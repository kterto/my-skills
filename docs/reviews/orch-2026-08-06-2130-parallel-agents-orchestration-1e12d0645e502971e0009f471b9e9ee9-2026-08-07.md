## Architecture

- [x] [arch-1|high] Remediation abandons the parent aggregate (plugins/my-skills/skills/orchestrator/SKILL.md:928)
  _fixed via main-agent · f8f05af · 2026-08-07_
  fingerprint: architecture|plugins/my-skills/skills/orchestrator/SKILL.md|remediation-abandons-the-parent-aggregate
  Rationale: After the first review or QA fix, plan_id becomes a FIX or QAF ID, so later reviewer and QA passes stop using the parent PACT and no longer evaluate the full leaf union.
  Fix: Keep an immutable root_plan_id for the parent PACT, track remediation plans separately, and always invoke join-level tester, reviewer, and QA against the root PACT with remediation artifacts as related inputs.

- [x] [arch-2|high] Contract amendments have no executable state transition (plugins/my-skills/skills/orchestrator/SKILL.md:895)
  _fixed via main-agent · 19f8733 · 2026-08-07_
  fingerprint: architecture|plugins/my-skills/skills/orchestrator/SKILL.md|contract-amendments-have-no-executable-state-transition
  Rationale: The amendment loop says to write a new contract and re-slice, but never allocates replacement IDs, rebinds the active PACT, maps invalidated leaves, or defines which completed work remains valid.
  Fix: Specify an atomic amendment transaction that allocates and verifies replacement contracts and plans, updates the active contract tree and leaf set, preserves only unaffected DONE leaves, then redispatches affected work.
  ADR: ADR: Contract amendment lineage and state transitions

- [x] [arch-3|med] The viability gates have contradictory normative order (plugins/my-skills/skills/orchestrator/references/config.md:55)
  _fixed via main-agent · ee81780 · 2026-08-07_

## Security

- [x] [sec-1|high] Resume treats branch-authored plans as executable authority (plugins/my-skills/skills/orchestrator/SKILL.md:305)
  _fixed via main-agent · 42de75e · 2026-08-07_
  fingerprint: security|plugins/my-skills/skills/orchestrator/SKILL.md|resume-treats-branchauthored-plans-as-executable-authority
  Rationale: Resume skips specification and contract generation and executes any matching working-tree PACT and FEAT artifacts without binding them to a prior run, allowing contributor-controlled plans to steer command-capable coders.
  Fix: Persist a run manifest bound to branch, preflight base SHA, spec hash, contract IDs, and leaf IDs; schema-validate recovered artifacts and require explicit selection when provenance is missing or ambiguous.

- [x] [sec-2|high] Lexical lane validation permits symlink escapes (plugins/my-skills/skills/orchestrator/references/config.md:110)
  _fixed via main-agent · 9a24068 · 2026-08-07_
  fingerprint: security|plugins/my-skills/skills/orchestrator/references/config.md|lexical-lane-validation-permits-symlink-escapes
  Rationale: Normalized relative paths and lexical containment still allow a lane-owned path to traverse a symlink into another lane or outside the repository, defeating the only isolation boundary between concurrent coders.
  Fix: Reject symlinked owned scopes and ancestors, canonicalize every existing path component, and enforce canonical repository and lane containment before and after writes.

- [x] [sec-3|high] Untrusted slicing output is promoted into authoritative prompts (plugins/my-skills/skills/orchestrator/SKILL.md:635)
  _fixed via main-agent · 37b1b48 · 2026-08-07_
  fingerprint: security|plugins/my-skills/skills/orchestrator/SKILL.md|untrusted-slicing-output-is-promoted-into-authoritative-prompts
  Rationale: The Explore digest is derived from contributor-controlled repository content, then passed verbatim with verify-and-freeze authority; embedded prompt injection can therefore be relayed into contract plans executed by later coders.
  Fix: Label the digest as untrusted data, require a strict structured schema, independently validate every requirement and glob, and surface rather than follow imperative text.

- [x] [sec-4|med] Mutable branch config controls fan-out policy and limits (plugins/my-skills/skills/orchestrator/SKILL.md:272)
  _fixed via main-agent · dc4f017 · 2026-08-07_
  fingerprint: security|plugins/my-skills/skills/orchestrator/SKILL.md|mutable-branch-config-controls-fanout-policy-and-limits
  Rationale: Parallelism mode and resource limits are loaded from working-tree config even though project policy requires config to use the merge-base trust anchor, so a reviewed branch can force nested execution and excessive concurrency.
  Fix: Load execution policy from the pinned merge-base, accept explicit CLI overrides as user authority, and validate bounded numeric values before dispatch.

## Bugs & Improvements

- [x] [bug-1|high] Join review omits every uncommitted leaf change (plugins/my-skills/skills/orchestrator/templates/reviewer.md:26)
  _fixed via main-agent · b749ffa · 2026-08-07_
  fingerprint: bugs|plugins/my-skills/skills/orchestrator/templates/reviewer.md|join-review-omits-every-uncommitted-leaf-change
  Rationale: The join claims the unchanged main...HEAD command yields the union, but coders never commit; staged, unstaged, and untracked leaf work is absent, so the reviewer can approve an empty or stale diff.
  Fix: Record the preflight base and review a complete working-tree snapshot that includes staged, unstaged, and untracked files, preferably through an isolated index whose hash is rechecked before accepting the verdict.

- [x] [bug-2|high] Resume cannot preserve a partial run (plugins/my-skills/skills/orchestrator/SKILL.md:282)
  _fixed via main-agent · 289c2c2 · 2026-08-07_
  fingerprint: bugs|plugins/my-skills/skills/orchestrator/SKILL.md|resume-cannot-preserve-a-partial-run
  Rationale: Resume detection runs only after the clean-tree preflight, but a PARTIAL run necessarily leaves uncommitted plans and implementation; additionally, the coder resumes IN_PROGRESS but not the BLOCKED state emitted by a halted leaf.
  Fix: Detect --resume before the clean-tree gate, verify the dirty state belongs to the selected run, preserve it in place, and define BLOCKED re-entry at the first unchecked task.

- [x] [bug-3|high] The outer join has no all-leaves-DONE barrier (plugins/my-skills/skills/orchestrator/SKILL.md:836)
  _fixed via main-agent · 9e6b935 · 2026-08-07_
  fingerprint: bugs|plugins/my-skills/skills/orchestrator/SKILL.md|the-outer-join-has-no-allleavesdone-barrier
  Rationale: The join only classifies BLOCKED results even though coder output may be IN_PROGRESS, allowing incomplete leaves and unchecked integration plans to proceed into reconciliation, simplify, tester, reviewer, and QA.
  Fix: Verify every required leaf and integration FEAT is DONE with all tasks checked, retry once, and route any remaining non-DONE status to PARTIAL before reconciliation.
